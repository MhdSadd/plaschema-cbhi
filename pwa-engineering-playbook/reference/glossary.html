PWA glossary

The smallest useful meaning of each term, with the decision it affects.

App shell

The minimum HTML, CSS, JavaScript, and icons needed to start the interface. It can be cached before business data.

Background Sync

A browser API that may run deferred work in a service worker after connectivity returns. Support is limited, so use it only as an enhancement.

Cache Storage

A browser store for HTTP request/response pairs, usually managed by a service worker. It is not a domain database.

Conflict

Two valid intentions cannot both be applied unchanged, often because a shared record changed while one device was offline.

Eventual consistency

Device and server copies may differ temporarily, but a defined process moves them toward an agreed result.

Freshness

How old local data may be before the app warns, refreshes, or blocks use.

Idempotency key

A stable ID for one user intention. Retrying with the same key must not create a second logical result.

IndexedDB

The browser’s transactional database for structured records, indexes, and large values such as blobs.

Lease

A temporary claim on queued work. It expires so another process can recover after a crash.

Manifest

JSON metadata describing an installable web app’s name, icons, start URL, colors, and display mode.

Outbox

A durable local queue of user intentions that the server has not fully acknowledged.

Precache

Files saved during service-worker installation so they are ready before a user asks for them offline.

Presigned upload

A short-lived, restricted URL that lets a client upload a file directly to object storage.

Progressive enhancement

A baseline experience works broadly; supported browsers receive richer capabilities without breaking the baseline.

Scope

The URL area whose requests a service worker may control.

Service worker

A browser-managed worker that can intercept requests, use caches, receive events, and update independently of a page.

Source of truth

The place allowed to make the final decision for one kind of state at one stage of the workflow.

Storage eviction

The browser removes best-effort origin data under policy or storage pressure.

Sync coordinator

The service that claims queued records, performs ordered stages, persists results, and schedules retries.

Waiting worker

A successfully installed new service worker that has not activated because an older worker still controls pages.
